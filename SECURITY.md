# Security Policy

## Reporting a Vulnerability

Please report security issues privately rather than opening a public issue,
using [GitHub's private security advisory form](https://github.com/ShahArpit89/photo-store/security/advisories/new).

Include steps to reproduce and the potential impact if known. This is a
small side project maintained by one person, so response times will vary,
but reports will be acknowledged as soon as possible.

## Scope

This is a photography e-commerce site in early development — no payment
processing or user accounts are live yet (see `docs/prds/` for what's
planned). Once those land, this policy will be updated to cover them
explicitly.
